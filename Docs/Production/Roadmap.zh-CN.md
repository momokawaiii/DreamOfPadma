## 交付顺序

现有原生规则与独立战斗模式是起点，应扩展已验证路径，不重建已退役的固定 Demo 链。下列为工作包，不代表代码/内容已经完成。

| 阶段 | 待完成工作 | 证据 / 依赖 |
|---|---|---|
| 1. 冻结章节内容 | 绑定黄金路径步骤、节点、Encounter 后一个 ACT、王庭结尾和奖励，接收最终卡牌数据 | 获批数值与规则/动作/状态覆盖；未决内容只阻塞相关工作 |
| 2. 建立打包基线 | 用现有内容产出可安装的离线 Win64 Development/Shipping 候选 | 两种配置启动/加载/退出，提前暴露 Cook/依赖错误 |
| 3. 地图生产 | 固定锚点/边/锁、地形生成、独立装饰 PCG、不可变清单及烘焙 | 确定性/锁路/MapKey/存档兼容及匹配包内视觉 |
| 4. 章节运行时 | 菜单/开场、事件/条件/效果流程、阶段池分配、教程进度/跳过/重玩 | 分支/分配持久化；同次奖励幂等，主动重玩可再次获奖 |
| 5. 可玩黄金路径 | 真实地图/日历/资源/ABC/合成/对白操作，Encounter、ACT、王庭及结尾 | 一次正常流程实际操作所有必需系统，并覆盖回滚/重开/继续 |
| 6. 表现与最终内容 | 获批地形/UI/卡牌/角色美术、动画、音频/VFX，替换原型数值/资产 | 用户视觉/输入验收、素材来源及最终内容校验 |
| 7. 最终双构建验收 | 用最终内容重新构建、安装两种配置 | [BuildMatrix](BuildMatrix.zh-CN.md) 证据；不以 PIE 单独证明完成 |

依赖允许时内容、地图、打包准备可独立推进。最终验收要求两种包使用同一经评审内容；早期原型打包成功不代表 Demo 完成。

## 明确暂缓

- Slate 剧情图编辑器、UEdGraph 编译器、对白/本地化录入工具和 Cue 编辑流程。
- 实际 Steam 提交、Steam 启动验证、云存档、成就与在线服务。
- FPS 玩法、完整战役及后续解锁才介绍的系统。
- 没有明确需求的通用量产工具、强制模块拆分或完整 Asset Manager 重构。

必需的剧情/教程运行时不暂缓，可由现有类型化表/资产和制作脚本供给。
