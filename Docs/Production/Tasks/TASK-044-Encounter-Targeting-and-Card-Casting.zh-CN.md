## 决定与范围

Encounter 普攻保留单位来源与卡面目标数量上限。用户最新补充要求先点普攻，再点击存活敌人立即打出，也可用取消／Escape 免费取消。HTML 默认单目标；舞女可在控制区选择双目标，第二个不同敌人点击后释放。长按任一阵营单位 500 毫秒，查看立绘、当前属性、技能／说明、等级及已有卡牌信息；等级、立绘和技能未配置部分如实标注。基础技能只借当前我方行动窗口校验一次出牌额度；效果来源是打出的卡牌／环境，不是该 C 单位及其 F/D/R／攻击属性。保留物理伤害的 C 克制、真伤、费用、目标范围、归墟／抗衡、弃牌与战斗回滚。

本轮仅实现 Encounter HTML。ACT 操作／绑定及 UE 制作不在改动范围。把未来 Sequencer 卡牌动效与材质／shader 表现记录为用户需求，不宣称 UE 已实现。用户确认的交互：单体牌拖到合法单位上松手只预览，再点击“确认释放”结算；鱼骸骤雨拖入战场后确认全部存活非核心目标范围。无效落点、取消、Escape 不消耗。点击／数字键可先选牌，再明确点目标／战场并确认作为替代操作，不立即对默认目标施放。

## 验收与检查

1. 先点普攻再选目标；单体模式点击合法敌人即释放，取消／Escape 不扣费。舞女保留明确的双目标选项；行动者切换时刷新选择。长按我方、敌方或倒下单位只打开详情，不施法；移动取消长按，查看后抑制松手点击。右键或聚焦后按 I 可替代。查看时敌方自动行动等待，已结算动画可继续播完。
2. 基础卡向上拖动时可见卡牌抬起与合法目标高亮；合法落点只预览目标和费用，明确确认时重新校验并提交一次。无效落点／取消不改游戏状态。点击／键盘替代操作也须选目标后确认。
3. 基础卡回执区分行动窗口归属与卡牌／环境来源，不出现 C 施法姿势、C 到目标连线、C 伤害归属或 C 属性加成。普通攻击保留单位来源。
4. 鱼骸骤雨表现为三波天降鱼骨，按真实回执命中双方；其他基础卡在指定目标处出现效果。保留倒下、最终一击、播放异常恢复与取消。
5. 保留已有引擎／回执／输入证据，按新操作维护现有 UI smoke 用例，运行局部语法及文档检查。用户明确负责浏览器交互／布局测试；不绕过此前本地文件访问策略拒绝，不增加大量审查轮次。
