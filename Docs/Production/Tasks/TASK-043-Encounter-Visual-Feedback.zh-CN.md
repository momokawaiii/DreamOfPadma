# TASK-043 Encounter 战斗动态反馈

- 英文原文：TASK-043-Encounter-Visual-Feedback.md
- 文档 ID：TASK-043
- 版本：0.2
- 状态：Review
- Primary：root；当前 Local 工作区
- 授权：用户要求在 HTML 原型中清晰标出 Encounter 行动者，并增加攻击来源到目标的战斗动画。

## 目标与决定

让每次 Encounter 行动都能看清：当前行动者、目标、命中、真实生命／护盾／抗衡变化，以及返回地图前的最终胜负。保留现有下次就绪行动条与全部数值规则。采用 SVG/CSS 表现保持离线打开方式，不增加渲染依赖。本任务不涉及 ACT 与 UE 制作。

包含直接相关的旧版倒下行动者卡死修复：“雨”击倒 Encounter 施法者且双方仍有存活单位时，按现有存活单位的下次就绪顺序推进。保留伤害数值、失败判定优先级、ACT 行为以及施法者存活时保留本次行动的规则。

## 所有权与允许路径

- root：Prototypes/HTML/app.js、index.html、encounter-fx.js、encounter-fx.css、encounter-fx.test.cjs、README 中英双文档；本任务双文档；00_INDEX、ProjectState、Changelog 双文档。
- 有界 worker：仅 Prototypes/HTML/engine.js 与 encounter-events.test.cjs。输出独立的临时表现回执；保留现有引擎测试与结算结果。
- 独立审查只读。保留其他现有本地修改。不修改 C++、UE 资产、配置，不暂存、集成或操作远端。

## 验收与验证

1. 用文字与单位高亮明确当前行动者，区分选中目标与后续行动顺序。
2. 显示攻击轨迹、命中与实际扣血；为吸收、抗衡、治疗、反伤和防御提供相应文字与特效。多目标攻击和雨的多波效果可辨认。
3. 播放过程中锁定指令与敌方自动行动；退出／重开时取消过期计时器，最终一击播放后再显示结算。失败指令不产生虚假命中。
4. 从结构化指令回执驱动特效，不解析本地化日志，不保存动画状态。保留 ACT 与精确战斗回滚行为。
5. 运行现有引擎测试、新回执／播放测试、JS 语法检查、AuditDocs 和 ValidateProject -Strict；独立审查实际文件。若本地文件浏览器策略阻止自动化，视觉验收保留人工检查，不绕过该限制。

## 学习证据与恢复

Agent 证据：展示规则结算与可取消的只读表现序列之间的分离。用户练习可选：辨认下一位行动者、观察双目标攻击与被抗衡挡住的命中，随后退出确认回滚。仅按用户要求恢复旧 HTML 文件夹副本，不丢弃共享工作区修改。

## 报告

用户报告后续问题：HTML 0.3 停在动作起手阶段，操作持续禁用。root 在现有 UI／测试／文档路径内修复，不改引擎。使用真实的默认 Playback 构造路径和校验接收对象的浏览器计时器替身复现；把原生计时器绑定到全局宿主，调度／绘制异常时解除表现锁，不重放已结算指令。之前 85 项测试绕过了默认计时器适配，不能证明此问题正常。

## 0.3 实现与历史证据

已实现：engine.js 输出结构化临时回执；encounter-fx.js/css 提供可取消播放、行动预测、单位剪影／高亮、SVG 轨迹和 CSS 命中；app 管理输入／敌方计时器并保留最终结算展示。HTML 顶栏为 0.3，未新增渲染库或网络依赖。修改均在允许路径内。

证据：85 项 Node 测试通过（47 原有引擎、20 回执、18 播放／输入／绘制）。后者使用模拟时钟与文档替身，执行真实 app 输入逻辑与绘制函数，不属于浏览器渲染证据。覆盖来源／目标身份、实际生命变化、护盾／抗衡／反伤、多目标／雨、精确回滚、最终胜负、取消、敌方准备时无效输入以及浏览器保留页面恢复。

独立审查发现并复核修复了 1 个 P1（无效输入使敌方计时器失效）、2 个 P2 边界（保留页面恢复、雨先前倒下单位表现）及减少动态效果下粒子的可见性。附加的倒下施法者卡死问题已修复：技能结束后战斗未结束时使用现有 nextActor 选择；存活施法者保留行动，已结束战斗不再推进。回执与真实 app 逻辑替身测试覆盖存活队友接棒。AuditDocs 通过（208 个 Markdown／104 对），ValidateProject -Strict、JS 语法和限定路径空白检查通过。独立 encounter_visual_review 复跑全部 85 项测试并确认倒下施法者修复，结论 Conditional pass，无剩余 P0–P2，TASK 保持 Review。浏览器视觉、缩放、原生动画与操作手感仍需人工验收，遵守了此前本地文件访问策略拒绝；见 README 六项 Encounter 检查。本轮未进行 UE 构建／PIE、提交、合并或推送。
