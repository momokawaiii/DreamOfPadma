# 时间与日历规则

- 英文原文（Agent 阅读）：`Docs/Rules/Time.md`

本文档是日历的规范契约。

## 层级

```text
一天 = 黎明 -> 晌午 -> 黄昏
七天 = 一个时代
七个时代 = 一个 Chapter
```

日历必须显式保存 `ChapterIndex`、`EraIndex`、`DayIndex` 和 `Phase`。不要在玩法代码中只用一个取模表达式推导全部层级。

## 状态变化要求

- 阶段变化是明确的事件。
- 进入黄昏时，明确启用 TASK-051 的教程局允许一次有界统治者野外扩张；无效推进、战斗或对话期间不执行。见[世界状态](WorldState.zh-CN.md)。
- 每天进入晌午时，每张已部署 A 的倾向向其附着 B 场域累加一次（2026-09-09 用户确认）。
- 日终效果与阶段效果分开。
- 时代变化发送 `EraChanged` 事件。
- Chapter 变化发送 `ChapterChanged` 事件。
- 测试覆盖第一天、第七天、下一个时代的第一天和下一个 Chapter 的第一天。
