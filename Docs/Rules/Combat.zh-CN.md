# 战斗规则

Encounter 按行动条和条件决定谁行动；ACT 是独立的实时战斗，两边有各自的角色配置和 GAS。局部战斗时战略时间暂停，胜利提交，失败或退出回滚。

普攻先选操作再选目标，可以免费取消。基础技能来自卡牌或环境，不继承某张 C 卡的攻击加成；物理伤害受克制，真伤不受这项克制。拖牌松手只预览，确认后才扣费和结算。

Encounter 每个符合条件的我方行动最多用一张基础卡。基础卡有独立弃牌堆，用尽洗回；ABC 主动技能默认可从沙盘发动，特殊限制按配置。

ACT 的 Tab 卡库把世界速度降到 1/10，每页五槽，用 1–5 选牌；打开时不接收移动和攻击输入。查看详情不攻击、不扣费；精确时序、例外和未定事项见英文。

详细依据、操作和证据见[英文原文](Combat.md)。
