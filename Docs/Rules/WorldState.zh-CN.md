# 世界状态规则

- 英文原文（Agent 阅读）：`Docs/Rules/WorldState.md`

世界变化通过稳定节点 ID 和明确事件表示。坐标是布局数据，不是节点身份。

持久化变化示例：

- 节点被发现
- 节点被清理/占领
- 驻军被击败
- 道路打开或关闭
- 派系归属改变
- 天气或环境状态改变
- 剧情选择应用
- 资源或遭遇表改变

每个变化都应该可以描述为命令、作为规则验证、记录为事件，并从存档恢复。

## 已确认 MVP 地图（2026-09-08）

普通手工／生成地图的移动遵循人工定义的节点和预设连线。六边形地表及文明 6 式斜俯视镜头属于表现，相邻装饰六边格不自动连通节点。下方 TASK-051 教程扩展明确选择生成六边形邻接边。

用户已接受分层存储：静态章节地图定义、.umap 表现、SaveGame 本局变化。稳定 NodeId／EdgeId 连接各层。占位、归属、设施、发现和已解锁道路由世界状态服务拥有；UI 发命令，检查合法性／付款后修改状态并产生事件。非法移动既不改变位置也不扣费。

见 [ADR-0005](../Decisions/ADR-0005-World-Map-Storage.zh-CN.md)。具体节点／连线、费用和条件仍需 D12／D03 回答；此决策不表示免费移动。

## 地图查看要求

用户于 2026-09-10 将地块查看改为单击固定右栏。悬浮仅更新地图高亮，不切换详情与动作目标；鼠标经过其他地块再进入侧栏时保持已点击目标。独立“移动到此处”命令移动选中的卡牌实例。查看本身不移动 Pawn、不扣费、不直接开战；模态层与按住卡牌手势阻挡背景输入。首版敌情全部公开，技术切图不是战斗事务。见[画面设计](../Design/ZH/06_MapAndPreparation.md)。

新教程生成器 v3 保留 55 格与七个关键节点，薪火台（`fire`）初始为王庭领地、驻守 1 人，归处有直达开放连接。部署存活 C 卡后可从归处选择该卡并移动至薪火台，按既有 Encounter 路由交战。旧 v1／v2 存档不补加该守军，测试此入口须新开教程。

## 教程部署与天平显示（TASK-052）

先选中手牌中的 A 或 B 卡，再明确点击目标地块。A 弹出部署确认；B 按实例列出此地已部署的 A 卡，非法选项禁用并显示原因。没有 A 卡时弹出说明。取消不扣费。确认冻结卡牌与地块 ID，并由既有 Core Deploy 命令在执行时重新校验卡区、阶段、地形、归属、附着资格与费用。悬停只改变地图高亮，不能切换详情、创建、改向或结算待确认操作。拖放和侧栏部署也走相同确认流程。过长列表纵向滚动。

UI 将中立 War=0 显示为我方 50／王庭 50。我方比例为 clamp(0.5 + 0.5 × War / warGoal, 0, 1)，王庭取其补数。液体动画不改变 War、配表初始值或既有胜利条件。

## 卡牌移动

每张卡定义有可移动／不可移动／条件移动三态，另有已配置标记；未配置不是默认许可。条件移动必须引用已实现的条件求值规则。A 与附着 B 成组且逐张校验，全部通过后才原子修改位置／费用；任一失败时整组和账本不变。UI 不能从模型或 ACT 阵容推定世界移动能力；逐卡政策、条件、费用与扣费时机仍是配置输入。
## 锚点生成与剧情检查点（TASK-048）

本节普通地图规则继续适用；固定绘景教程采用下方明确扩展。

FixedNPC 与 MainStory 节点在不同种子中保留配表指定的身份和坐标。前者固定放置 NPC；后者提供供后续剧情检查的人物相遇／完成记录。允许绕路，抵达配置的检查点时一次性检查 Seen／Completed 并记录命中／错过分支；此前绕路不立即判定错过。不增加全锚点通行／胜利条件，道路标记仍须明确配表。晌午外抵达只记录相遇／检查点，不打开对话；到晌午再进行节点对话。本局快照冻结生成的节点、有向边与检查点定义。见 [ADR-0007](../Decisions/ADR-0007-Anchored-Map-Generation.zh-CN.md)。

## 固定绘景教程扩展（TASK-051）

用户最新决定授权固定 2.5D 教程绘景、生成六边形野外以及宜居地形占领。`tutorial-painted-v1` 明确生成邻接边，普通地图含义保持原状。七个已有关键 ID 保留规则和特殊道路，采用教程专属绘景坐标。地形、高度、轴坐标和归属是数据，材质动画只负责表现。不可通行的水域／山地不能部署、移入或占领；野外边保留原道路的解锁条件，不能绕过必需的道路标记。

玩家通过正常付费晌午移动占领，A／B 仍整组原子校验。进入无驻军的中立或敌方宜居野外直接转移归属，不虚构驻军或战斗；野外占领不增加战争天平、不伤害核心、不发放战略清理奖励。黄昏时统治者按确定顺序至多占领一个相邻、空置、中立的宜居野外，不消耗共享玩法随机流。此 Demo 扩张不攻击已占领的玩家地块、不生成军队、不模拟 AI 经济。存档／回滚冻结生成布局和归属，读取时按地图类型使用可信配置校验。见 [ADR-0009](../Decisions/ADR-0009-Painted-Tutorial-Hex-Map.zh-CN.md)。
