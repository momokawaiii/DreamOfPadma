## 交付与玩家路径

下一交付是达到发行质量、可安装的离线 Win64 Demo。它不是完整 MVP，不包含实际 Steam 提交/接入、云存档、成就或在线服务。Development 与 Shipping 都需测试。剧情编辑器暂缓，可玩剧情/教程运行时仍必需。

`启动 → 主菜单 → 剧情开场 → 第零章地图 → 移动 → 日历/资源 → ABC 卡 → 合成 → 节点事件/对白 → Encounter → ACT → 占领王庭 → Demo 结尾`

第零章就是新手教程。核心步骤要求玩家真实操作并改变状态。Encounter 与唯一 ACT 节点分开、按序体验；不设 FPS 节点。其他系统在解锁时介绍，不全部塞进教程。

最终 Demo 路径使用获批生产值，用户将提供最终卡牌文档。现有标明临时性的表仍是开发样例，不能满足最终验收。缺失数值不代表允许自行补默认值。其他胜利条件如何衔接王庭结尾、准确节点安排及具体奖励仍需内容决定。

- 内容策略允许时，普通节点可重复同一事件。随机剧情有效范围随日历阶段变化。

## 跳过与重玩

教程状态区分 NotStarted、InProgress、Completed 和 Skipped。跳过整段教程标记 Skipped，初始化配置的教程后奖励并允许继续，不能伪装为实际完成。

设置中可以开始新一次教程。主动重玩可再次获奖；同次运行中读档或崩溃恢复不能重复发奖。跳过表现 Cue 只快进表现，不执行教程结算。具体奖励及跨次重玩的背包/档案行为仍待确定。
