# 第零章 Demo 规则

- 文档 ID：RULE-CH0-001
- 版本：1.1
- 状态：范围与行为已接受；内容数值和实现待完成

做一个可安装、离线运行的 Win64 第零章 Demo：主菜单和开场 → 地图教学 → Encounter → 单个 ACT 节点 → 王庭 → 结尾。教程要求真实操作，不能只播演示。

最终地图用固定 Seed 烘焙成 3D 地形，PCG 只装饰，剧情锚点和道路由玩法数据决定。阶段剧情首次分配后要保存，读档不重抽。

跳过教程要记为跳过，不能冒充完成；同次读档不重复发奖，主动重玩可再次获奖。具体奖励和正式卡牌数值仍待定。

ACT 最终要一个新 Padma 角色，含连招、技能及代表性的投射物、召唤、执行技。界面可以重做，玩法含义需保持一致。

功能开发可先无音频，发行候选要正式音频，但不要求配音或完整英文。Development、Shipping 都要验收；联网和剧情编辑器暂缓。公开包只能用自有或适用授权素材，研究占位要替换并查引用。

详细依据、操作和证据见[英文原文](ChapterZero.md)。
