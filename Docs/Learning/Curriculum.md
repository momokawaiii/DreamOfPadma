# Learning Curriculum

- Chinese companion for user reading: `Docs/Learning/Curriculum.zh-CN.md`

| Project output | Primary learning |
|---|---|
| Module skeleton and build script | UE modules, Build.cs, Git, build pipeline |
| Calendar and synthesis service | C++, USTRUCT, GameplayTags, data design, numerical testing |
| Battle vertical slice | Gameplay, condition-driven Encounter action timelines, reactions/interrupts/extra actions, complete ACT RealTimeAction loop, GAS preparation, AI, animation logic, and physics basics |
| Ability presentation | Anim Montage, Anim Notify, Niagara, materials, UI |
| Hex world and node mutation | level design, World Partition, PCG, procedural data |
| Save round trip | USaveGame, serialization, migration, local persistence |
| Strategic sandbox, Encounter, and ACT RealTimeAction adapters | input mapping, action-timeline gates, shared Tab card repository, ACT MVP background blur and 1/10 bullet time, movement/attack input gating, five-visible-slot paging, camera, possession, inertia, and mode/state patterns; exact Encounter precedence and total page count are deferred |
| Post-MVP asset audit and package | Asset Manager, cook, packaging, performance debugging |
| Environment slice | Nanite, Lumen, virtual shadows, weather, water, foliage |
| Release build | platform input, SDK boundaries, hot-update strategy, release governance |

Each task should name one or two learning targets and record evidence in its completion report.

Use [Development Learning Workflow](Workflow.md) to turn each target into a prediction, user-performed practice, observable evidence, teach-back, and transfer. Completion of an Agent-produced artifact is not by itself evidence of user mastery.
