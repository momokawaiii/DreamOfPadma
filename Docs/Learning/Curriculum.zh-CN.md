# 学习课程

- 英文原文（Agent 阅读）：`Docs/Learning/Curriculum.md`

| 项目产出 | 主要学习内容 |
|---|---|
| 模块骨架和构建脚本 | UE 模块、`Build.cs`、Git、构建流水线 |
| 日历和合成服务 | C++、`USTRUCT`、GameplayTags、数据设计、数值测试 |
| 战斗垂直切片 | Gameplay、条件行动条遭遇战、反应/打断/额外行动、完整 ACT RealTimeAction 闭环、GAS 准备、AI、动画逻辑和基础物理 |
| 能力表现 | Anim Montage、Anim Notify、Niagara、材质、UI |
| 六边形世界和节点变化 | 关卡设计、World Partition、PCG、程序化数据 |
| 存档往返 | `USaveGame`、序列化、迁移、本地持久化 |
| 战略沙盘、遭遇战和 ACT RealTimeAction 适配器 | 输入映射、行动条门、共享 Tab 卡牌仓库、ACT MVP 背景虚化与 1/10 子弹时间、移动/攻击输入门、每页五个可见卡槽分页、镜头、占有、惯性和模式/状态模式；精确遭遇战优先级与总页数延期 |
| MVP 完成后的资源审计和打包 | Asset Manager、Cook、打包、性能调试 |
| 环境切片 | Nanite、Lumen、虚拟阴影、天气、水面、植被 |
| 发布版本 | 平台输入、SDK 边界、热更新策略、发布治理 |

每个任务都应写出一到两个学习目标，并在完成报告中留下证据。
