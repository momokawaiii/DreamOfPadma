### 世界地图与悬浮

地图占主要画面；日历／时代、心流、算力、全局熵、信仰、威慑力和战争天平由对应服务提供，放在紧凑 HUD。具体排布是 UI 建议。

| 信息 | 依据 | 表现建议 |
|---|---|---|
| 地块名称／类型、地形／词缀、控制方 | mygame 8–9 与世界状态 | 标题及简短地形／归属行 |
| 双方 A、附着或独立 B、C 人物／工事、失败造物 | mygame 3、8、11 | 按双方分组；显示卡牌身份、附着与相关状态 |
| 设施、稳定值、可用操作 | mygame 3、8 | 状态与已配置操作反馈，不代填产出数值 |
| 已知路线与条件路径 | mygame 9 | 已知连线用实线／虚线；条件只显示允许公开部分 |
| 原生生物、巡逻／侦测情境 | mygame 8–10 | 观察者获准信息；未知不等于无人 |
| 场景／操作入口 | 用户补充 | 点击／进入控件及明确的不可用原因 |

悬浮发起只读查询。首版将敌方地块内容全部传入 UI 和局部模型，包括身份、数量、附着与状态。保留未来按策略生成视图的边界，但当前策略为全部公开，不能实现成迷雾或未知敌方；统治者自身 AI 侦测不变。

### 局部地块场景

用更近的镜头显示同一地块的地形、实体和设施。选中人物或工事后查看卡牌身份、归属、已批准状态以及技能／操作。人物动作、受击、死亡与建筑受损／摧毁都表现权威事件。

建议按需复用地形／局部场景模板并配置节点摆放，不要求每个节点一份独立 .umap。静态定义把 NodeId 映射到 SceneDefinitionId 和关卡／表现软引用。已部署卡实例与 EntityId 仍归世界状态所有。局部 Actor 从这些状态重建；打开关卡不会凭空获得新卡、重置损伤或复制设施。

区分技术层打开关卡与玩法层权限、移动、创建战斗。场景绑定带版本的节点上下文，拒绝过期／错误加载完成，失败保留此前有效状态。返回时恢复镜头／选择位置，不撤销合法世界操作。真实战斗失败／退出才走完整战斗事务。

每个可表现节点都需要明确的可查看性／场景可用性结果。每个世界地块可提供获准的地形信息；没有玩法节点的装饰地块不能虚构 NodeId 或合法移动。

## 建议的全局配置分类

| 分类 | 内容 | 边界 |
|---|---|---|
| ACT 出战 | 独立 ACT 角色、武器、角色技能及地形特性限制 | TASK-036 静态定义；TASK-035 选择与资格 |
| FPS 出战 | 独立的未来配置入口 | 已确认不在首版可玩，仅显示未来能力状态 |
| 共享基础技能 | 共享身份／槽位编组；查看 Encounter 与 ACT 的各自效果 | TASK-020 提供，不替代 ACT 战斗中的 Tab／子弹时间 |
| 关系与成长 | 剧情角色、关系进度、已解锁增益、下一已配置条件；有数据时显示历练／技能成长 | 最小关系／增益服务；不虚构 NPC 或数值 |
| 增益总览 | 来源、目标、适用模式／卡类、条件、持续时间／时钟、生效或失效原因 | 汇总权威服务的只读视图，不成为另一套 buff 执行器 |
| 卡牌图鉴 | 已知卡及批准的发现限制 | mygame 3 要求首次成功召唤 C 前限制更多细节；确切政策由卡牌／内容任务负责 |

全局配置面向玩家，不是开发者配表编辑器。模型／表格软引用仍在 Unreal 中填写。打开或浏览页面不会装备物品、应用增益或主动发送日历推进命令。更改配置发送校验命令并接收结果。允许编辑时机、全局预设与本局状态归属，以及未保存修改／开页期间时间的处理仍为 D20／D27。不能把另一套 ACT Tab 的 1/10 时间规则套到这里。

未来模式可以显示清楚的不可用状态，但不能将其表格强转为 ACT 行类型，或把未实现模式标为可玩。基础技能身份共享已确认用于 Encounter／ACT，不自动扩展到所有未来模式。

## 建议的最小关系增益设计

mygame 第 3 页明确提到 NPC 好感可影响某类 B 卡，第 5 页把日常历练与主角属性联系起来。用户进一步要求查看关系带来的增益。建议首个内容样例选一条已配置关系和一条已批准增益路径，目录保持可扩展；这不等于首版制作完整关系网络。

独立保存 StoryCharacterId、关系进度／解锁状态、BonusDefinitionId／版本及来源事件身份。记录效果作用对象、领域／时钟与剧情来源条件。好感不等于合成相性；剧情角色也不自动是 ACT 角色。

关系服务校验更新、解析有资格提供的增益来源；资源／卡牌／战斗所有者通过已有契约执行相应效果。UI 只展示结果视图。影响 B 卡合成的增益不能全塞进 ACT GAS；无关增益不继承启示的不可叠加规则。

实现前由 D28 确认具体 NPC／事件／增益、阈值与幅度、授予／移除／叠加条件、时机、支持目标和全局／本局持久化。保存权威来源／解锁状态，幂等重建临时效果。战斗会修改的本局部分进入 TASK-028／029；全局成长不会被默认回滚。
