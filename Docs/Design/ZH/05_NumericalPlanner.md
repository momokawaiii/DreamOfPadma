## 1. 数值目标

数值 MVP 首先要让游戏可解释、可复现，再追求规模。每个可见结果都应该能追溯到输入、公式或表格、带种子的随机投掷和明确来源。

数值策划负责系数、表格、测试夹具、模拟和调平报告。没有更新系统或战斗策划案，数值策划不能改变规则含义。

## 2. 数值原则

1. 系数放在数据里，不放在玩法代码里。
2. 候选 C 选择概率与合成成功率分离。
3. 心流和算力分成两本账。只允许明确设计、具有真实代价、时机和风险的资源转换循环；某些设计中运气可以补偿代价。
4. 全局熵是风险/策略变量，而不是单一惩罚条。
5. 使用稳定测试夹具和带种子的随机流。
6. 先测试边界值，再调平均体验。
7. 在 DebugGame、Development 和 Test 版本暴露计算追踪。
8. 把发动场景作为规则门，同时让卡牌消耗、冷却和输入时序保持数据驱动。

## 3. 数值词典

| 变量 | 含义 | MVP用途 |
|---|---|---|
| `Flow` | 卡牌和技能资源 | 抽牌、打牌、召唤、技能。 |
| `FlowCap` | 心流上限 | 手牌/资源压力和赊账边界。 |
| `Computation` | 沙盘操作资源 | 移动、建造、节点操作和部分效果。 |
| `ComputationCap` | 算力上限 | 赊账和恢复边界。 |
| `GlobalEntropy` | 共享不稳定度 | 合成修正、灾祸压力和世界后果。 |
| `Faith` | 召唤者/核心信仰值 | 合成修正、卡牌效果和可能的胜负。 |
| `CoreLife` | 核心生命 | 统治者核心生命归零是已确定的 MVP 胜利条件；同一数值也可以支持未来失败条件。 |
| `Stability` | A 卡/工事耐久 | 摧毁和战场状态。 |
| `WarBalance` | 玩家/统治者拉锯值 | 达到玩家侧边界是已确定的 MVP 胜利条件。 |
| `Threat` | 统治者压制/升级值 | 巡逻、反攻和卡牌惩罚。 |

### 3.1 发动相关的数值输入

发动渠道是规则门；其中可调的数值属于数据：

- 基础非 A 卡只有在建立合法局部战斗场景后，才支付配置的消耗。
- ABC 卡主动技能可以在不进入战斗的情况下从沙盘支付配置的消耗并发动。
- 遭遇战行动条数值、优先级、反应/打断窗口、额外行动限制，以及“每个符合条件的玩家行动回合最多一张基础非 A 卡”应与全局日历阶段分开，并明确命名。
- ACT MVP 的交互契约确定为点击 `Tab`、打开背景虚化的五张卡面板、将世界时间降至 1/10、禁止移动和攻击输入、只接受基础非 A 卡输入、保持场景惯性以及每页 1—5 个可见卡槽。持续/切换行为、冷却/资源消耗、页面边界行为、总页数和生命周期概率仍属于数据/评审事项。
- 卡牌生命周期转移（弃牌、回牌、冷却或其他明确结果）必须有明确代价或条件，不能由 UI 自行推导。

## 4. 合成公式

### 4.1 向量候选选择

A、B 的稀疏向量为：

```text
V = AVector + BVector
S_i = dot(V, CandidateVector_i)
Softmax_i = exp(S_i / T) / sum(exp(S_j / T))
```

候选集合先按允许的共同标签过滤。`T` 是配置的温度。候选选择投掷和成功率投掷是两个独立层级。

如果 B 卡直接使用、没有走 A 的积累路径，则 A 权重按 `1` 处理，B 卡原本会传给生成 C 的突变属性不转移到 C。这仍是系统规则提案，必须在实现/试玩任务中作专项决定后才能作为规范规则使用。

### 4.2 成功率

```text
D = abs(BFinalFlow - CTargetFlow)
  + abs(BFinalEntropy - CTargetEntropy)

P_success = (100 - D
             + M_affinity
             + M_global_entropy
             + M_faith) %
```

当前采用的相性修正示例：

```text
万能受体    +10%
介稳受体    -10%
异形受体    -20%
```

当前采用的全局熵修正描述：

```text
M_global_entropy = -(CurrentGlobalEntropy / 10) ^ 1.5
```

当前采用的信仰修正：

| 信仰 x | 修正 |
|---|---|
| 95 <= x <= 100 | `10 + 1.0 * (x - 95)` |
| 80 <= x < 95 | `4 + 0.4 * (x - 80)` |
| 40 <= x < 80 | `-4 + 0.175 * (x - 40)` |
| 20 <= x < 40 | `-15 + 0.55 * (x - 20)` |
| 0 <= x < 20 | `-33 + 0.9 * x` |

是否限制到 0%-100%、负熵/极高熵如何处理，以及修正值的单位，都还没有冻结。

### 4.3 计算示例

下面只用于确认理解：

```text
A = 地痕
  向量 = {奥秘: 80, 禁忌: 20}

B = 蓍
  向量 = {奥秘: 90, 知识: 10}
  最终场域 = [心流 4, 熵 8]

候选 C = 犹格索托斯
  向量 = {奥秘: 80, 禁忌: 10, 知识: 10}
  目标心流 = 2
  目标熵 = 10
  相性 = 万能受体
```

合成向量是 `{奥秘: 170, 禁忌: 20, 知识: 10}`。该候选的示例点积为：

```text
170*80 + 20*10 + 10*10 = 13,900
```

共鸣距离为 `abs(4-2) + abs(8-10) = 4`。如果当前全局熵为 `40`、信仰为 `50`：

```text
M_affinity       = +10
M_global_entropy = -(40 / 10)^1.5 = -8
M_faith          = -4 + 0.175*(50-40) = -2.25
P_success        = 100 - 4 + 10 - 8 - 2.25 = 95.75%
```

这不是平衡结论，只是说明候选选择和成功计算是两个独立层。

## 5. 西格玛骰子和失败后果

当前项目澄清为：

- 合成主要结果只有成功或失败。
- 西格玛骰子不替代，也不暗中修改主要成功率公式。
- 失败后不发放奖励。
- 如果保留西格玛骰子，它只能决定另行定义的非奖励失败后果，不能产生隐藏成功、部分成功或奖励。
- 失败侧后果不是第三种成功生成 C 的状态。

以下表格故意留空，等专项实现决定记录后填写：

| 骰子输入 | 非奖励失败后果 | 资源/熵影响 |
|---|---|---|
| 待定义 | 待定义 | 待定义 |

是否保留西格玛骰子、骰子数量、面数、阈值、重掷规则、非奖励失败后果和是否向玩家公开，都是开放决定。

## 6. 资源预算

原始资料中的示例值，用于后续调平：

| 操作 | 资料示例 |
|---|---:|
| 移动 A 卡 | 2 算力 |
| 移动 C 人物/明确配置的失败侧对象 | 4 算力 |
| 移动工事 | 6 算力 |
| 进入合成概率阶段 | 沙盘规则示例中为 3 算力 |
| 有限赊账 | 资料说明为当前上限的 30% 以内 |
| 默认资源获取 | 资料说明无特殊文本时至少获得上限的 50% |

这些不是最终初始值。MVP 应使用命名配置档，使测试档可以宽松，试玩档可以单独调平。

## 7. 战斗数值规则

MVP 数值流程需要支持：

- 攻击伤害和真实伤害。
- 普通攻击伤害先经过防御。
- F/D/R 属性关系。
- 状态层数和消耗时机。
- 生命、稳定值和核心数值分池。
- 战争天平事件增量。
- 威慑力阈值效果。

原始关系是克制造成双倍伤害，弱克造成一半伤害。朋克时代取消关系。次世代使克制关系翻倍，但到底是翻倍最终乘区还是翻倍额外加成，仍待确认。

第一组数值测试夹具应覆盖：

- 基础攻击对等防御。
- 高防御下的真实伤害。
- D 对 F、F 对 R、R 对 D。
- 朋克和次世代变体。
- 零层、一层和多层状态。
- 同时发生的战争天平事件。

## 8. 战争天平和威慑力调平

战争天平从 50/50 开始，通过有名字的事件增量移动，而不是无法解释的每秒漂移。

威慑力应有每日增长和事件变化。25/50/75/100 阈值保留为原始提案的数据点；对应的玩家卡牌惩罚和峰值响应需要试玩验证。

任何阈值在冻结前，都必须能解释：

```text
旧值 + 事件列表 + 每日结算 = 新值
```

## 9. 测试夹具和调平报告

数值测试应包含：

- 信仰 `0、19、20、39、40、79、80、94、95、100`。
- 全局熵 `0`、低值、阈值值和极端值。
- 共鸣距离 `0`、接近匹配和超范围匹配。
- 无候选、单候选和多候选。
- 相同种子至少重复两次。
- 失败且没有奖励。
- 有明确代价/风险、带有限行动数并包含随机补偿情形的资源转换循环。

每份调平报告要注明配置档、种子、卡组、试验次数、结果分布和结论。为了保留学习证据，最好同时保存截图或导出的计算追踪。

## 10. 开放数值决定

- 所有资源和核心数值的初始值与上限。
- 概率限制范围和修正值单位。
- Softmax 候选过滤与归一化方式。
- 是否保留西格玛骰子、骰子规格和非奖励失败后果表。
- 赊账与资源循环限制，包括每个循环的代价和风险。
- 次世代克制翻倍的确切含义。
- 战争天平事件幅度和胜利阈值。
- 威慑力惩罚和峰值响应。
- 手牌上限、心流上限和牌堆耗尽惩罚。
- 遭遇战行动条优先级、先攻修正、反应/打断优先级、额外行动规则、非回合窗口和结束回合资源效果。
- ACT MVP 的持续/切换行为、冷却/资源消耗、页面边界行为和总页数；`Tab`、背景虚化、禁止移动/攻击输入、1/10 世界时间和每页 1—5 个可见卡槽已经固定。
- 基础非 A 卡弃牌/回牌/冷却的具体概率，等相关卡牌实现时再确认。
- ABC 主动技能的消耗和冷却是否在战斗内外都适用。

## 11. 学习目标

本基线用于学习数值设计、概率建模、Softmax、确定性模拟、边界测试、数据表、经济循环、战斗平衡、遥测和基于证据的迭代。
