# MVP 策划基线 03 - 战斗 / AI 策划案

- 文档 ID：`DESIGN-MVP-COMBAT-AI-001`
- 状态：高层 MVP 基线已验收；详细时序与优先级规则仍延期

Encounter 用条件和行动条调度，ACT 用实时动作，两边共享需要一致的规则含义，但执行和配置分开。伤害、状态、死亡和胜负由规则结算，表现负责把结果播出来。

统治者 AI 根据局势行动，并随威慑等状态变化。核心生命归零和战争天平是已确定的 MVP 胜利方向；精确行动优先级、反应窗口及内容数值仍要逐项确定。
