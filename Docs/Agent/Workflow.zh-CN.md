# Agent 工作流

- 英文原文：Workflow.md
- 当前流程：TASK-045；替代旧示例／TASK 的通用流程默认值，具体游戏决定与技术验收仍有效。

## 默认执行循环

读取现状与当前 TASK → 检查受影响来源 → 实现 → 必要检查 → 更新 TASK → 按需交给用户试玩。

一个 Primary 可同时协调和实现。串行工作留在当前 Local；实际并行且独立的写入需要隔离，或用户要求时才使用 worktree。任务耗时长不自动产生新聊天，新聊天由用户提出。常规修改不经过 planner／reviewer／tutor 接力。

## 上下文开销

- AGENTS 放稳定约束；ProjectState 放当前事实；TASK 放本次变化；Role 放专长；Skill 放操作流程。
- 索引用于找来源，不用于加载全库。只读相关英文段落；核对受影响文件，复用已读且未变化的内容。
- TASK 输入应注明所需决定或段落。旧长清单作查找参考，开工不通读全部前置报告，也不同时读两种语言。
- 恢复工作只需结果、当前文件、检查和下一步；可能变化的事实重新核对。
- 工具只输出匹配段落或简要结果，不反复打印整文件、未变状态或成功日志全文。

## 何时委派

当独立问题或不重叠补丁能节省时间、利用专长或隔离大量中间内容，且收益值得额外模型调用时，使用子 Agent。依赖前一步的操作留在主 Agent。先安排一个有用子任务；配置上限不是数量目标。

工具支持时，优先 fork_turns=none 并提供自足工作包，否则只传相关历史。不得为缩短提示省略必要约束。工作包包含：结果、来源路径／段落与相关决定、权限、检查、简短返回格式。告知 writer 共享代码库，须保留并适配他人修改。

子 Agent 读适用 AGENTS 和指定来源，不重复整套开工阅读。返回路径、结论／改动、证据、未解风险。相关追问复用已有子 Agent；没有具体矛盾时不重复其已完成探索。Primary 负责接口衔接与最终交付。

## 验证与审查

| 改动 | 最少有效证据 | 独立审查 |
|---|---|---|
| 文案、布局、可逆表现配置 | 相关语法／资产校验及可复现用户检查 | 用户要求或出现具体额外风险时 |
| 有界游戏逻辑 | 对变化的规则／状态转换测试；原生代码变化需 Editor 编译 | 存在下行风险时 |
| 存档／回滚、确定性、公共契约、GAS 所有权／生命周期、模块／构建依赖、共享二进制集成 | 定向回归及适用构建／运行证据 | 集成前一次有范围的只读审查，除非用户明确选择其他验收方式 |

- 用户试玩负责交互／布局，不表示 C++ 编译或存档／回滚正确性已验证。
- 未变代码／环境的有效检查可复用。改动或失败后重跑受影响检查，不因换了角色就重跑全套。
- Markdown 修改后 AuditDocs；仓库结构／共享配置变化时 ValidateProject -Strict；UE 构建／Editor／PIE 保持串行。
- 审查核对实际指定 diff 与证据；复查修复及受影响边界，不再次审查全项目。用户免除 review 不免除必要技术检查。
- 如实报告未知项，不因通用清单要求额外截图、视频、复述或审批。

## TASK 与状态

新交付使用简版 TaskTemplate；同一验收边界的小修补／澄清修改现有 TASK。只读解释不额外创建实现任务。

Backlog＝未授权；Ready＝相关决定和范围足够；In Progress＝已有负责人；Review＝确有 reviewer 或用户检查待完成；Verified＝适用检查／必要验收通过；Done＝另行获准的集成已完成。没有额外门槛时可跳过 Review。Verified 不表示获准集成或推送。

用户当前请求可授权一个有界 Backlog 工作；写入前记录相关决定并推进状态。仅在缺失游戏含义、真实范围／所有权冲突或必要授权时询问；旧状态本身不构成再次确认理由。

结果、路径、检查与剩余工作在 TASK 记录一次。Primary 同时作为串行协调者时，可负责共享状态。优先级／状态／决定变化才改 ProjectState；规则／架构含义改变才改对应来源；交付行为或流程补一条简短 Changelog。中英同步。

开发中的教学可选。用户请求解释时解释；只有选定课程练习才走预测／实践／复述，不因旧 TASK 含学习栏目就启动教学。教学时参考 Docs/Learning/Workflow.md。

## 可复用提示

用户：
~~~text
在当前 Local 继续 TASK-xxx。
结果：<可见行为或修正>。
验收：<我要看到／测试什么>。
约束：<只补充新约束>。
仅讲解 <需要学习的主题，可省略>。
~~~

子 Agent：
~~~text
TASK-xxx 的有界工作包：<结果>。
输入：<路径／段落＋相关已接受决定>。
权限：只读，或只写 <路径>；父 Agent 负责关闭任务／更新状态。
检查：<必要证据>。返回：路径、结果、检查、未解风险。
你不是唯一写入者：保留他人修改并适配。
~~~
