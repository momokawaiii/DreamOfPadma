# 世界地图编辑

- 文档 ID：CONTENT-WORLD-MAP-048
- 版本：0.3
- 状态：当前编辑工具与独立标出的离线 Demo 烘焙目标；用户交互验收待进行

直接编辑 `DA_FirstRegion_Map` 中的节点、位置、连边和剧情检查点，保存后在 `L_PadmaWorld` 开新局检查。独立编辑地图已移除，重建脚本也不再生成它。

固定剧情锚点不能被随机生成破坏。地形、道路和 PCG 只负责表现，不能偷偷决定通路。最终还要做带版本的 3D 烘焙和清单校验；当前工具不等于这一整套已经完成。
