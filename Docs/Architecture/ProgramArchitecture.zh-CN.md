# 程序架构

- 文档 ID：ARCH-PROGRAM-001
- 版本：0.5
- 状态：边界已接受；区分当前实现与离线 Demo 目标

目前只有 DreamOfPadma 一个 UE 运行模块，内部按职责分目录。Core 管规则和数据，Game 把流程接起来，Gameplay 管战斗，World 和 UI 负责表现。

玩家操作先变成指令，校验成功后才改状态，再通知画面。UI、动画和特效不能自己扣资源或结算奖励。定义、局内状态和表现对象分开，存档不存 Actor 指针。

Encounter 和 ACT 分开执行；正式第零章仍有待实现部分。具体接口和依赖见英文及模块图，不能把架构目标当成已经写好的功能。

详细依据、操作和证据见[英文原文](ProgramArchitecture.md)。
