# ACT 开发契约

- 文档 ID：ARCH-GAMEPLAY-ACT-001
- 版本：0.3
- 状态：已有原生原型；单角色完整 ACT 目标已接受，实现未完成

最终 ACT 要做一个新 Padma 角色：能移动、转镜头、普攻连招、放技能、命中和打断，并各有一个代表性的投射物、召唤和执行技。还要能从战略层进入，再正确胜利、失败或退出。

GAS 管技能生命周期，Montage/通知管动作时机，命中由权威逻辑结算。取消、死亡和切场都要清掉输入、伤害窗口、移动限制及特效。

现有原型和陈千语实验提供参考，不等于正式内容完成。先做模型和 3C 的学习单元，也不代表缩小最终目标。

详细依据、操作和证据见[英文原文](ACTDevelopmentContract.md)。
