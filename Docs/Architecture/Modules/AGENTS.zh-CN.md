# 模块文档 Agent 约定

- 英文原文（Agent 阅读）：`AGENTS.md`
- 上级规则：`../AGENTS.md`

## 目的

`Modules/` 下的每个目录都是一个逻辑模块 Agent 的技术归档位置。对应的 C++ 模块、Actor 或资源尚不存在时，也可以先建立模块目录；此时 README 需要记录计划中的边界，并明确当前还没有实现。

## 所有权

- 模块 Agent 负责自己的模块 README、实现说明、测试以及明确允许的 Source/Content 路径。
- 架构师 Agent 负责跨模块边界、依赖方向、共享契约和结构性 ADR。
- Review Agent 检查代码、数据、策划规则和模块文档是否一致。
- 模块 Agent 不能悄悄把规则转移到其他模块，不能创建万能 Manager，也不能仅为了名称对称而创建新的运行时模块。

## 模块工作流程

1. 阅读上级架构规则和模块 README。
2. 阅读相关英文策划案/规则文档。
3. 说明任务范围和受影响路径。
4. 实现或记录最小的连贯变化。
5. 同步更新英文和中文模块文档。
6. 增加测试或可复现的人工检查。
7. 任何公开契约、依赖、存档或网络变化都要请求架构 Review。

## 模块 README 章节

模块 README 应保持以下内容最新：

- 目的和状态。
- 负责人和允许修改的路径。
- 负责事项和不负责事项。
- 对外数据与运行时契约。
- 命令、事件和集成点。
- 依赖关系和禁止依赖。
- 数据资产和校验。
- 测试、调试命令、存档/网络行为。
- 实现计划、风险和学习目标。

英文 README 是 Agent 使用的规范源，中文 README 是用户阅读镜像，不能独立引入新的语义。
