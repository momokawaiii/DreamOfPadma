# ADR-0006 原生 HTML 切片、分表目录与表现

- 文档 ID：ADR-0006
- 版本：0.1
- 状态：用户授权 TASK-046 下已接受的实现决策

用户已验收 HTML 0.4 并授权原生 UE 实现，同时允许其临时数值用于标注的 Demo 内容。旧子任务未确定的首版细节以已实现 HTML 行为为准。更广 PDF 范围与 FPS 游玩仍延期。

## 决策

- 保留现有模块中的 Core/Game/Gameplay/World/UI 逻辑目录。增加内置 GameplayAbilities/GameplayTags/GameplayTasks、CommonUI/UMG/Slate、Niagara 与 ProceduralMeshComponent 依赖，用于战斗、原生页面和六边形几何。Combat 仅读参考，不引入 GASCompanion 或 Aurora。
- Demo 入口将类型化表解析为验证后的值快照，不在每帧加载表。目录按内容域保存多张软引用表；跨分片重复 ID 直接报错，不按表顺序覆盖。Encounter 和 ACT 效果采用不同的行类型及独立数据。卡牌、ACT 角色、ACT 武器、FPS 枪械与展示身份分离。资产绑定使用类型化 Data Asset 软引用；实例／存档仅保存 ID。
- 小型测试内容在明确入口／加载边界同步读取；这不是开放世界流送架构。软引用本身不保证异步加载。烘焙覆盖可玩目录与地图根；缺失／错型引用给出可定位错误。
- Core 纯命令拥有日历、卡牌经济、移动、合成和可存储状态值；GameInstance 子系统适配安全 SaveGame 边界。操作先验证再发布；战斗快照覆盖移动扣费、随机流、卡库、标记与阵容。
- Gameplay 拥有临时 GAS Actor 与模式执行。Encounter 先决定行动资格，再执行能力；ACT 使用实时输入、移动、攻击任务及自己的绑定。角色 ASC 随战斗 Actor 销毁，独立环境／卡牌来源负责基础卡效果。表现结束不能再次扣费、伤害或提交。
- Game 组合层从待处理的地图请求开战，胜利仅投影一次；失败／退出／启动失败恢复战前状态。战斗中沙盘时间不推进。ACT 卡库以 0.1 速度模拟并拒绝新移动／普攻输入；清理恢复普通速度。
- 使用原生 CommonUI 页面／控件组合及可复用三维展示舞台。归处标签切换界面和外观，不逐标签切关卡。局部战斗可使用独立关卡；GameInstance 状态跨关卡保存，待处理请求仅在 Actor 就绪后接入。关卡表现与静态图定义、动态存档分离。
- 对话定义目前包含文本台词与选项；立绘、语音和对话序列需后续扩展表现。规则完成一次性发奖。战斗 Sequencer、Niagara、Montage 接口只负责表现，不拥有奖励／伤害。缺美术明确使用占位，不把缺失内容当作已配置成功。
- 保留 HTML 当前未覆盖项。新增规则／能力行为仍需代码；已有行为新增内容只需配表。同骨架、插槽、动画图、Niagara 参数及新 shader 仍需要制作。

## 证据

TASK-046 负责构建、定向规则／GAS／目录／回滚检查与可玩资产。不承诺联网 ACT 重放、正式美术或生产流送能力。运行／手动验收与编译结果分别记录。
