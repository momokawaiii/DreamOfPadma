# ADR-0016：参考效果保留独立参数

先让参考版 Shader 保留原本的参数含义，不把所有效果硬塞进旧通用参数。每个槽位可以选参考版母材质：DA 管数值和颜色，MI 管贴图；编辑器生成 MIC，游戏创建 MID。

脸部随头和光转动的 SDF 值由组件计算，通过原有 CPD 的空余分量传入。材质预览没有组件时使用默认值。删除 DA 覆盖后，下次应用会恢复继承值。

这是接入结构决定，**不代表视觉复刻已验收**。逐槽、转光、转头和实际角色的验证由 TASK-057 跟踪。参考模型多出的眼白、口腔等分片，也不能只靠换 Shader 补出来。

详见 [英文技术约定](ADR-0016-NPR-Reference-Response.md)。
