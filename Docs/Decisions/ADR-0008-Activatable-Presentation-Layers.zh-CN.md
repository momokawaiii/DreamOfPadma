# ADR-0008 可激活表现层级

- 英文主文档：ADR-0008-Activatable-Presentation-Layers.md
- 状态：Accepted
- 日期：2026-09-09
- 范围：TASK-050–052 原生表现；依据用户要求的 CommonUI 层级及其 Slate／材质动态扩展。

## 决策

常驻界面拥有独立的 CommonUI 页面栈和覆盖层栈。玩法页与备战页均为真正的可激活控件；被动 HUD 属于页面。详情、菜单、对话与确认框是覆盖层栈上的模态可激活控件，仅最顶层接受输入，底层页面继续可见。返回先恢复上一覆盖层，再回到页面。激活控制路由与焦点，不负责玩法结算，也不代表世界暂停。

控制器把稳定 ID、只读规则/战斗数据投影为视图，并向现有服务提交命令。覆盖层导航是临时状态。按压手势负责 500 ms 查看阈值、移动取消及释放点击抑制；世界输入和键盘快捷键服从覆盖层的输入所有权。

地图单击固定右侧详情与动作目标；悬停只控制地图高亮。点击换目标使用仅详情投影，保留顶部、目标、手牌、小地图和阶段控件，不替换排队的完整视图。A／B 部署在打开模态层前捕获卡牌与点击节点：A 确认，B 列出同地 A 及可用性或无目标说明。预览调用 Core 命令值拷贝；确认重新校验真实命令，取消不扣费。

绘景地图只有一个导航所有者。CommonUI 页面把按下／释放路由到原生 Slate 地图，由地图维护导航状态并处理 Home、点击、中键拖动和滚轮。取消会清空持续导航并释放自身捕获。控制器轮询不重复处理绘景 WASD；独立三维相机仍由控制器负责。输入释放和取消因此与输入开始处于同一所有权链路。

视觉时机与激活分离。原生 Slate 不透明度／平移和 UI 材质遮罩提供入场、悬停扫光与立绘显现，不要求也不声称使用 Widget Blueprint UMG 动画轨道。当前入场顺序为标题／副标题／立绘／信息／动作分别在 0.05／0.09／0.12／0.18／0.25 秒开始，动作间隔 35–40 毫秒。输入所有权与返回不等待该序列。立绘 MID 拥有自身纹理与裁切，着色器时间不会移动立绘图像。每个按钮独立的悬停 MID 避免共享扫光状态。材质着色器时间控制不暂停 Slate 激活或玩法。

战外详情读取卡牌实例，战内读取即时战斗快照。优先使用可选模型立绘，其次使用现有卡牌插画。缺失的等级/养成数据明确显示未配置。角色能力与玩家共享技能库分区展示。依据 Combat.md/TASK-044，遭遇战详情阻挡敌方自动行动；已提交动作可以完成。ACT 保留现有计时，包括独立的 Tab 技能库策略；本 UI 修改不决定 D27 备战计时。

退出生命周期显式清理手动构建的 CommonUI 栈及其控件池／Slate 缓存，不能只依赖未包含这些栈的 WidgetTree 根。控制器 EndPlay 调用幂等 `ShutdownPresentation`，断开回调、取消输入并释放资源。按钮闭包强持有的 MID 必须以 transient package 为 Outer，不能通过 Screen 反向保活 GameInstance。此边界以单次 GC 释放测试及真实 PIE Stop 检查验证。

## 影响

CommonUI 节点的生命周期与输入所有权独立于绘制样式。UI 域材质画刷目前提供主要的纸纹／深蓝／金色皮肤，旧九宫格资产继续保留。对向流体战争条把既有规则分值显示为互补份额，中性进度从 50:50 开始；平滑显示与中央图形不增加玩法状态。资产路径、材质参数与创作命令集中维护在 [StrategyPresentation](../Content/StrategyPresentation.zh-CN.md)。

连续地形与 PCG 仍遵守 ADR-0007，属于 World 表现。绘画教程的带版本 Core 网格另由 ADR-0009 约束；UI 几何和动画不成为存档权威。覆盖层父上下文、保留的详情区域、捕获的部署目标及输入恢复需要针对性回归覆盖。TASK-052 的运行时截图与交互验收记录在其任务证据中；实现该动态序列本身不代表验收通过。
