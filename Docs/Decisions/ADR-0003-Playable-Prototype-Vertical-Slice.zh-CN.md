# ADR-0003：固定可玩原型垂直切片

- 英文原文（Agent 阅读）：`ADR-0003-Playable-Prototype-Vertical-Slice.md`
- 状态：`Accepted`
- 日期：`2026-09-07`
- 实现状态：未授权；本次仅编写文档
- Owner：Integration Coordinator / Architect Agent
- TASK 契约：`../Production/Tasks/TASK-006-Playable-Prototype-Cluster.zh-CN.md`

## 背景

干净的 DreamOfPadma 项目已经验证 PIE 可以启动，但目前仍只有生成的运行时模块。参考项目 `E:\2026ue\padma` 展示了一条有价值的第一条可玩路径：选择 SLG 地块，将地块上下文带入局部场景，展示卡牌数据，召唤角色，并查看角色技能。

项目需要在完整 M1 规则基础完成前看到可操作的表现层。一个窄小的垂直切片可以提供这种进展，同时避免复制旧原型的万能管理器、UI 直接改状态、直接使用随机函数、未决玩法默认值或整棵资源树。

## 决策

1. 近期集成 Goal 是一个固定 fixture 的可玩切片：
   `Sandbox 地图 -> 选择一个 Demo 地块 -> 进入其对应 Encounter 场景 -> 显示一张 Demo 卡 -> 出牌 -> 召唤一个角色 -> 查看其技能列表`。
2. 该切片使用明确标记为 playtest 的 fixture。Demo 地块到场景的映射、一个角色、一张卡和少量技能只是表现 fixture，不是最终世界图、卡牌生命周期、战斗规则或正式内容命名空间。
3. 切片继续放在当前生成的 `DreamOfPadma` 运行时模块中。不创建永久 UE 模块拆分，不启用 GAS，不添加外部玩法插件，也不修改引擎关联。
4. 使用可替换的会话/切场上下文，通过节点、场景和出生点等稳定 Demo 身份跨场景传递状态。该 Demo 可以在此边界后使用直接关卡跳转；这不决定最终 World Partition 或流送方案。
5. 项目自有 Demo 资源放在 `Content/Padma/Demo/` 下。旧原型仍只作为参考。不授权整体复制 `E:\2026ue\padma\Content`、原地修改外部资源或导入未经 Review 的资源依赖树。
6. UI 将输入转换为已批准的强类型指令路径，并消费结果/事件或只读视图。UI、地图 Actor 和卡牌 Widget 不能成为权威玩法状态。
7. 第一切片读取角色技能定义并演示卡牌到角色的召唤。不激活技能，不结算战斗，不选择伤害/状态公式，也不实现 Encounter 行动条细节。
8. 完整 Unreal 自动化测试体系和 PIE 内 Debug 面板属于后续工作。第一切片要求编译证据和手工 PIE 证据；只有不扩张范围时才补充窄范围服务测试。

## 后果

- 用户可以较早得到一条可重复的可玩演示路径。
- 后续 World、Gameplay 和 UI 实现可以替换 fixture，而不改变指令/结果/事件的方向。
- 该切片有意保留正式 ID 命名空间、导入管线、资源策略、卡牌生命周期概率、路线语义和 Encounter 精确时序未决定。
- 第一版实现可能需要在现有临时模块中加入最低限度的 UMG 依赖。该依赖只能由已批准的实现 TASK 及其唯一指定写入者加入；本 ADR 本身不修改依赖。
- 地图、二进制资源、中心构建配置、Editor 会话和 PIE 通道是共享资源，因此端到端验证保持串行。

## 未采用的方案

- 把参考项目的 `CoreGameManager` 及其全部相关资源作为第一版直接移植。
- 在展示一条可玩路径之前，先完成完整 SLG 图、卡牌生命周期、战斗系统和 Debug 面板。
- 让 Widget 直接调用 `SpawnActor` 或直接修改世界/玩法管理器。
- 把 TASK-005 确定性随机基础设施设为固定、无随机 Demo fixture 的硬前置。
- 把可用的 Debug 面板当作可重复服务或规则验证的替代物。

## 保留的延期决策

- 战斗路线的敌我共同结算，以及沙盘和 Encounter 场景是否共用 World Partition。
- 移动成本、资源策略、卡牌生命周期、牌库/抽牌行为及任何奖励或失败语义。
- Encounter 行动条优先级、响应/打断窗口，以及尚未决定窗口的精确出牌额度。
- ABC 卡在局部战斗内的合法性、ACT 实现、GAS 所有权和外部插件采用。
- 最终稳定 ID 命名空间、导入格式、存档模式变化、网络权威以及表现资源的授权/选取。
- 已接受策划基线中明确标记为 Open、Proposed、Deferred 或 playtest-only 的其他全部内容。
