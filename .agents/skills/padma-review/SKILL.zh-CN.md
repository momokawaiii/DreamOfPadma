# padma-review

按适用 AGENTS 读取指定 TASK 验收、实际 diff 与相关来源段落。只沿受影响依赖扩展，不加载全部被引用设计文档。

核查具体行为、已接受规则及适用的所有权／确定性／存档／生命周期风险。复用仍有效的检查证据，有实际疑问时才补定向检查。修复后只复查修复及影响边界，不重新审查全仓库。

先报告可行动问题：P0 数据丢失／无法构建；P1 验收或重大规则／契约失败；P2 重要边界／回归风险；P3 可选改进。每项需路径、影响、验证／修复方向。避免纯风格问题。

结尾给 Block／Conditional pass／Pass、检查与未验证风险。区分待用户试玩与代码缺陷。保持只读，不合并／推送，不仅凭 worker 叙述认可结果。
