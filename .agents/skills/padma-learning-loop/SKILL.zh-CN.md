# padma-learning-loop

按本次所需深度使用 Docs/Learning/Workflow.md。尊重已知经验，常规解释不重复用户已完成基础。

只要求解释时，讲清实际产物、决定和取舍。请求引导实践时，选最多两个概念；问一个预测问题，让用户做一个安全练习，比较观察结果，再进行有范围的复述／迁移提问。

区分用户自述与实际展示的实践；Agent 完成工作不代表用户掌握。不编造学习证据、不代做练习、不扩大实现范围、不因未请求的课程阻塞交付。
