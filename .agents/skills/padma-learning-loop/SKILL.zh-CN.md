# Padma 学习闭环 Skill

- 英文原文（Agent 读取）：`SKILL.md`

通过项目当前正在制作的真实产物来学习。Agent 完成了工作，并不等于用户已经学会。

## 建立学习契约

1. 阅读任务的 Goal、验收标准、学习目标和相关英文模块文档。
2. 一个任务最多选择两个主要概念，先补前置知识，无关内容延期。
3. 实现前先定义每个目标的证据。证据必须可观察，例如预测、图示、调试器状态、用户亲自执行的命令、受控数据修改、测试解释或复述。

## 执行闭环

1. **定位：**解释这个概念为什么存在，以及它位于项目运行流程的哪里。
2. **预测：**展示结果前，让学习者先说应该发生什么。
3. **观察：**只指出最小相关文件、UE 面板、日志或测试。
4. **练习：**给出一个由学习者亲自完成的安全操作。
5. **验证：**把真实证据和预测对照，并解释差异。
6. **复述：**让学习者用自己的话解释概念和一种失败模式。
7. **迁移：**让学习者说明同一概念如何用于另一个 Padma 模块或后续功能。

## 记录证据

在任务完成报告中分别记录：

- Agent 产生的产物证据；
- 用户亲手产生的证据；
- 已证明理解的概念；
- 误解或未回答问题；
- 下一个前置知识或迁移练习。

不要为了教学扩大功能范围，也不要默默替学习者完成练习。学习目标分为 `Introduced`、`Practiced` 和 `Demonstrated`；只有复述成功并且存在可观察证据时，才能标为 `Demonstrated`。
