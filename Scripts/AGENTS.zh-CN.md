# 脚本约定

- 英文原文（Agent 阅读）：`Scripts/AGENTS.md`

- 脚本必须可以安全地重复运行。
- 缺少必要工具或路径时，脚本应给出清晰错误并失败。
- 没有明确且受保护的命令，不得从脚本删除项目或用户数据。
- 构建和测试输出放在被忽略的 `Saved/` 或 `Artifacts/` 目录下。
- 优先使用仓库相对路径和显式的 `-EngineRoot` 参数，不要写死机器路径。
- 新脚本必须在 `README.md` 或相关 `Docs/` 文档中有简短用法说明。
- Markdown 修改后运行 `AuditDocs.ps1`，并在完成报告中记录结果。
- Agent 读取英文规则；修改英文规则时必须同步修改本文件。
