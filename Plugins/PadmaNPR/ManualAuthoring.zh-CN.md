# 手动生成 NPR 角色：使用说明

详细约定见 [英文说明](ManualAuthoring.md)。现在可以真正输入网格、指定贴图、预览和生成资产，不需要运行 Python。

## 操作步骤

1. 打开 **窗口 → Padma NPR Studio**。
2. 在内容浏览器选中骨骼网格，点击 **读取选中网格 / 接入配置**。也可以直接填写右侧 Mesh。
3. 展开 **Surfaces → Slots**。按槽名把需要转换的槽从 `Keep Original` 改为 Cloth、Skin、Face、Hair、Eye 或 Brow。辅助透明层先保留原材质。
4. 填 BaseColor、Normal。粗糙度、金属度、AO 可以用独立图，也可以重复选择同一张打包图并分别指定 R/G/B/A。没有图时使用常量；Glossiness 勾选反转。
5. 调整 Style 参数。需要 SDF 时填正确的头部骨骼和轴向；默认根骨骼只适合先看基础效果，不代表自动校准好面部。
6. 点击 **构建 NPR 预览**。左侧是真实角色视口；鼠标操作相机。Preview 分组可以调灯方向、选择同骨架动画和暂停播放。修改贴图、风格后需再次构建预览。
7. Output Folder 填一个新的 `/Game/...` 目录，点击 **生成 NPR 角色**。等待编译后，工具保存材质、MI、运行时 DA 和接入配置。
8. 选中关卡角色，点击 **应用到选中角色**，再保存生成的 MIC 和关卡。角色需只有一个与输入网格匹配的 Mesh 组件。组件里可以指定 Key Light，随后运行 PIE。

## 输出资产

- `M_NPR_Manual_<槽序号>`：根据该槽输入生成的资源接线。
- `MI_NPR_Source_<槽序号>`：源材质实例。
- `DA_NPR_Character`：运行时风格配置。
- `DA_NPR_Recipe`：保存网格、贴图语义等接入输入，之后可以重新读取。
- `T_NPR_LinearWhite`：数值图默认值。

重新生成时请换一个输出目录；本版不会覆盖旧资产。更改接入输入后，旧生成结果不能直接套给新角色，必须重新生成。

生成资产后重开编辑器，要直接应用已保存的 DA，请点击右上角 **已有 DA / 参考版**，使用原来的读取 DA、应用和恢复功能。陈千语原来的参考版配置继续保留。

## 输入与效果边界

这是**基础不透明 NPR 入口**，不是把任意贴图自动变成陈千语参考效果。各类型共享基础 Cel；Hair 使用方向性高光，Face 可选 SDF，Matcap 可选。Skin 不代表物理散射，Eye 不代表已实现角膜光学。

- Normal 需要 UE 标准切线法线压缩；自定义 RG 编码图和虚拟纹理暂不支持，会提示错误。
- AO、粗糙度、金属度、SDF 需要关闭 sRGB；工具不擅自修改你的原图。
- 该基础 Shader 根据指定主光方向着色，**暂不接收真实场景光照阴影，也不是多光源光照模型**。需要已校准的参考效果时继续使用原参考版。
- SDF 需要符合约定的通道、左右镜像和阈值方向；不能从普通 BaseColor 自动生成。
- 透明辅助层、半透刘海等请保留原材质。自动匹配、描边、雨雪和第二角色验证后续再做。

Shader 数学集中在 `PadmaManualCore.ush`；Slate 管输入和预览，C++ 生成服务管校验、编译、保存，运行时组件管 MID 与头部/光方向。当前已验证生成、真实预览视口、面板重开及生成配置的 PIE 接入；尚未做打包验收。
