## 现在如何使用

1. 打开关卡，选择要应用 NPR 的角色。
2. 在内容浏览器选择已经配置好的角色 DA，打开 `Window → Padma NPR Studio`，读取所选资产。
3. 检查 DA 的槽名、类型和源 MI。陈千语使用 `DA_Chen_NPR_Reference`，九个槽使用 Reference Response。
4. 源 MI 填贴图；DA 的 Reference Scalars / Vectors 调艺术参数。参考模式下，普通 Face/Hair 等结构中的同名概念不一定生效。
5. 点击“应用到角色”，保存生成的材质实例、DA 和关卡。修改 DA 后重新应用。
6. 进入 PIE 检查。编辑器使用生成的 MIC，运行时组件重新创建 MID，因此不要只改生成的 MIC 来调整效果。

模型资产的默认材质可以仍是旧材质；关卡角色 Mesh 组件的覆盖材质优先。恢复操作只负责插件拥有的绑定。当前独立预览区仍是占位，使用现有关卡检查效果。

眉毛已经换回与 Padma 网格配套的贴图；九类参考母材质已补齐骨骼网格使用配置，并通过一次实际 PIE 九槽 MID 检查。尚不代表打包和性能验收完成。

## 下一版用户流程

建议按钮叫 **“生成 NPR 角色”**。它生成配置和材质绑定，不把动态光照烘焙成静态贴图。

```text
选择骨骼网格、输出目录、可选的关卡角色
    ↓
逐槽选择：保留原材质 / 衣服 / 皮肤 / 脸 / 头发 / 眼睛 / 辅助层
    ↓
手动指定 BaseColor、Normal、Roughness、Metallic、AO 等
    ↓
指定通道、法线编码、头部骨骼、风格参数
    ↓
校验 → 生成 NPR 角色
    ↓
得到源 MI + 角色 DA + 应用用 MIC
    ↓
如果选择了关卡角色，自动挂组件并应用；PIE 自动使用 MID
```

只选网格时先生成资产，不暗中创建角色蓝图或修改模型默认材质。一个角色有多个 Mesh 组件时，必须指定目标组件。

## 贴图该怎么填

| 输入 | 需要明确什么 | 没有时的目标行为 |
|---|---|---|
| BaseColor | 颜色图、UV，或者明确使用纯色 | 纯色材质才使用常量 |
| Normal | RGB/RG 编码、绿通道方向、强度、UV | 平坦法线 |
| Roughness | 贴图和通道，还是常量；是否实际是 Glossiness | 使用风格默认粗糙度；Glossiness 显式反转 |
| Metallic | 贴图和通道，还是常量 | 非金属默认 0 |
| AO | 贴图和通道 | 默认 1 |
| SDF | 采样通道、左右约定、头部朝向 | 禁用 SDF 或提示所选方案缺少输入 |
| 发丝方向/偏移 | 模型切线或方向图的约定、偏移遮罩 | 仅使用已实现并说明的基础切线方案 |
| Matcap | 图、贡献遮罩、强度 | 关闭该层 |
| 刘海区域/阴影辅助层 | 区域遮罩、必要的独立几何 | 条件不满足则关闭 |

打包图可以重复指定为粗糙度、金属度和 AO，但要分别选 R/G/B/A。**不假设 `_P` 永远是 ORM，也不假设同名贴图适合另一个网格。** 颜色图与数值遮罩的 sRGB、压缩方式不同，工具应检查而不是擅自修改共享原图。

只有 PBR 图可以做基础风格化，但不能自动生成正确的面部 SDF、发丝方向和刘海分区，也不能保证复刻特定角色。当前参考 Shader 仍有专用图和通道约定；真正支持上述输入，需要补齐对应的适配层，不能只增加几个贴图选择框。

## Shader、C++、面板如何分工

| 层 | 负责什么 |
|---|---|
| 面板 | 收集选择、展示按槽输入、错误与输出结果；不写 Shader 公式 |
| 编辑器生成服务 | 校验、转换明确支持的输入、创建 MI/DA、调用应用与保存 |
| 语义适配层 | 把“粗糙度 R 通道”等输入映射到所选 Shader；不支持就提示 |
| 薄母材质/函数 | 资源采样、坐标输入、原生材质设置、调用 HLSL |
| HLSL | Cel、SDF、各向异性高光、Rim、Matcap 等数学 |
| 运行时组件 | MID 生命周期、头部和灯方向更新，不扫描文件或运行 Python |

下一版拟保存一份编辑器“接入配置”，记住网格、贴图语义和输出位置，方便重复生成。它负责资源输入，DA 负责风格参数；源 MI 是生成结果。现有手工 MI 在明确迁移前仍保留原有权威，不能两边同时编辑却互相覆盖。

当前代码入口是 `PadmaNPREditorModule.cpp`（面板）、`PadmaNPRStudioLibrary.cpp`（应用/恢复）、`PadmaNPRProfile.h/.cpp`（配置与参数）、`PadmaNPRComponent.cpp`（运行时）。详细路径和 Shader 分工见英文指南。较大的 Reference Shader 目前仍是节点算式逐项翻译，后续按类型拆成命名函数，逐块验证画面；不直接用旧通用原型替换它们。

## 各向异性高光是什么

各向异性是沿发丝与垂直发丝的高光响应不同。灯光或视角改变时，高光通常仍会移动、变形；不是“灯转了高光也固定”。稳定不动的亮带可能来自绘制高光、Matcap 或人为固定方向，需要检查实际计算路径才能判断。
